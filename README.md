# Tree-Tracking-System
A web-based system developed to manage and monitor tree inventory, locations, maintenance activities, risk assessments, and tree removal records around Shah Alam.

Objectives
To provide a centralized platform for recording and monitoring tree information throughout its lifecycle.

Key Features
Tree inventory management (CRUD)
Tree species management
Location management
Tree maintenance records
Risk assessment management
Tree removal and replantation records
Dashboard statistics and charts
Interactive tree location map

Technologies Used
PHP
HTML
CSS
JavaScript
Bootstrap
Oracle Database (SQL)
XAMPP
Leaflet.js

Installation
Install XAMPP and configure PHP with Oracle OCI8.
Place the project folder inside htdocs.
Create the required Oracle database tables.
Configure your own database connection using config/db.example.php.
Start Apache and access the project through your local browser.
